# How to build your sales page with Claude (DRAFT for Isabelle to review)

You get 3 things: the kit (a zip file or one single file), the brand palette PDF (all-brand-palettes.pdf), and this page.

## Before you start
- Open the Claude desktop app and start a new chat. If you have Claude Code, open a new empty folder in it instead. That is the easiest way, because Claude can run the build for you.
- Gather these: your checkout link, your product name and price, any copy you already have, and your images (product mockups, testimonial screenshots, a photo of you, a picture for each bonus).

## The steps
1. **Set up your folder.** Unzip `sales-page-generator-kit.zip`. You get a file called START-HERE.md and a folder called kit. Put both together in a new empty folder, for example "sales-page" on your Desktop. In the Claude desktop app, start a new chat, click **Add folder** and pick that folder. Then type: "Read START-HERE.md and start." Do not paste the text of START-HERE into the chat: Claude needs the kit folder next to it. If your app cannot add a folder, attach `START-HERE-SINGLE-FILE.md` as a file (not pasted text) and say: "Follow this file."
2. **Your copy.** Claude asks if you already have your sales page copy. If you do, paste it. If you don't, Claude asks you the questions one at a time and writes it for you.
3. **Your brand.** Open all-brand-palettes.pdf, pick one of the 42 palettes, screenshot its card, and upload the screenshot when Claude asks. You can also upload an image of your own brand instead.
4. **Your images.** Upload all of them at once. Claude looks at each one, places it where it belongs and shows you a table. Fix any row by number, for example "image 5 to section 6".
5. **Your page.** Claude builds it and opens it. Click "Edit layout" at the bottom to change text, colors, image sizes and spacing. Click "Save draft" to keep your changes.
6. **Make it load faster.** When your page is built and checked, open MAKE-YOUR-PAGE-LOAD-FASTER.html (or the .txt file), copy the prompt and paste it into the same Claude conversation. Claude makes your images lighter and guides you step by step.
7. **Publish.** Ask Claude for the paste-ready file. Paste it into a custom code or HTML block on Kajabi, GoHighLevel, Systeme.io or any builder that accepts HTML. The publish guide in the kit has the exact clicks for each one.

## Good to know
- Claude never makes up results, numbers or testimonials. If something is missing, you will see a clear note on the page for you to fill in.
- Check every testimonial: make sure you are allowed to use it. If a screenshot shows a buyer's email or phone number, cover it before you publish.
- After you paste the page into your builder, hard refresh it (Cmd+Shift+R) so you see the newest version.
