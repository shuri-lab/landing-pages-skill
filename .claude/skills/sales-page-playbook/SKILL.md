# Sales Page Playbook

This skill lives inside the playbook folder (the repo https://github.com/shuri-lab/landing-pages-skill; the folder may be called `landing-pages-skill` or `sales-page-playbook`). The full instructions are in the repo's `START-HERE.md`.

1. Find the playbook folder: it is three levels up from this file (`../../../START-HERE.md`). If this skill was copied elsewhere (e.g. `~/.claude/skills/`), look for a `landing-pages-skill` or `sales-page-playbook` folder; if there is none, ask the person to clone https://github.com/shuri-lab/landing-pages-skill and give you its path.
2. Read `START-HERE.md` in full and follow it from Stage 0 (or from F1 in Part 2 if the person only needs a checkout, bump, upsell, thank-you page or emails). It tells you which stage file to read next.
3. If the person asked to **take the test**, read `test/TEST.md` first and follow its rules (inputs, client answers, what to hand in).

Never skip the house-style and copy-rules files (`knowledge/house-style.md`, `knowledge/copy-rules.md`): they are why the pages built with this playbook need few feedback rounds.
