# ChatGPT image prompts: [Offer name] ([Brand])

> A filled example that worked: `examples/rickey-headstart/image-prompts.md`.

## How to use (for the person running ChatGPT)
1. Attach first: **[style image file]** (the hero/offer mockup: the style to match) and **a clear front-facing photo of [founder]** (for the likeness).
2. Paste the **Style brief** once.
3. Paste the prompts one at a time (or "make all N, one image each").
4. Save each image with the file name in its header and put them all in `[PROJECT]/page-images/`.

---

## Style brief (paste first)

You are making a set of product mockup images for "[Offer name]", a [price] [format] by [founder] for the brand [BRAND]. Every image must look like it belongs to the same set as the attached offer image:
- Clean, bright, photo-realistic 3D product mockup on a pure white or very light grey seamless background, soft studio lighting, soft natural shadows, slight depth of field.
- Brand colors only: [main color name + hex], [dark + hex] and white. [Main color] used for accents, swooshes, buttons and highlights.
- Branding: the [BRAND] logo is [describe it in words: letter style, color, any badge]. Use it the same way as in the offer image.
- Typography on screens and covers: [describe: e.g. heavy, bold, condensed sans serif, all caps for titles], like the offer image.
- [Founder] must look exactly like the attached photo: same face, skin tone, [glasses/hair/etc.], friendly smile. [Clothing style].
- Devices: [laptop / current iPhone / tablet / printed booklets: whatever the offer uses].
- Spell every word exactly as written in quotes. No other readable words except small grey placeholder lines.
- Never show money amounts, income, earnings, sales numbers, payout notifications, prices, star ratings, follower counts or testimonials.
- No brand logos other than [BRAND] (no Nike, no Apple logo, no platform logos).
- Landscape 16:10, high resolution, no border, no watermark.
