# Design rules (full table)

The house-style list (`knowledge/house-style.md`) is the short version. This is the long version from the first rounds, with exact values and why.

| Rule (general) | Rickey example (exact values) | Why |
|---|---|---|
| Hero order: alert bar → logo → proof pill → H1 → **hero image directly under the H1** → subheadline → CTA → fine print. | Figure moved under `</h1>` with `margin:10px auto 34px`. The kit default puts the figure last. | #16. Later rule: on an iPhone 16 (393×852) the alert bar through the button must fit the first screen. |
| Dark-section rhythm: a black band about every third section, plus a black alert bar and footer. | v1: only section 5 dark. v2: sections **2, 5, 8, 11** dark, plus footer and alert bar. | Without it the page read as "one continuous section" (#16). |
| One hard accent for anything clickable. Mostly white and black. | Red #D30805 on buttons, check marks, numbers, accent words | Brand vibe: "raw, real, hit-record energy". Clarity. |
| Brand red on black is for large text only. Small text on black uses a lighter derived red. | #D30805 on #101017 = 3.4:1. Small text uses #FF6B63 (6.8:1). | WCAG readability |
| Videos: muted, autoplay, loop, `playsinline`, a poster frame, `preload="none"`. Load and play via IntersectionObserver (`rootMargin:'300px 0px'`), pause off-screen, respect `prefers-reduced-motion`. | 5 Cloudinary videos, `w_360,q_auto,ac_none,du_12`; posters `w_360,so_1` `.jpg` | About 0.9 MB per video, no autoplay blocking (muted), no wasted bandwidth |
| Infinite strips: the item set plus an `aria-hidden` duplicate set; a keyframe to `translateX(calc(-50% - gap/2))`; pause on hover; edge-fade mask; under reduced motion, no animation and `overflow-x:auto`; off-screen images forced to eager load. | Slider: 60 s, gap 18 px, images 210 px (160 px on phones). Video carousel: 45 s, gap 16 px, cards 200 px (150 px), radius 18 px, `border:2px solid var(--on-dark)`, `box-shadow:5px 5px 0 var(--accent)` | Seamless loop, accessible, loads reliably. Later: "Sliders must never run out" (double the track until it's wider than the screen; carousel capped at 1040 px). |
| No horizontal scroll at 375 px. Never leave negative margins on something moved outside its column. | `.vcar` `-18px` margins made `scrollWidth` 411. Fixed to `0`. | Mobile is 90% of traffic |
| Sticky side media for long stories, on desktop only. One column at ≤820 px. | `.reel` / `.side3` `position:sticky; top:48px`; `@media (max-width:820px)` single column | Fills the empty column beside a long story |
| Custom CSS only when the kit has no class for it. Put it in one commented `<style>` block at the top of `body.html`. | The reel, slider, logo strip, top logo, `.duo`, `.addon`, footer wordmark, alert bar, `.vcar`, `.side3` | Kit rule. Keeps the base theme intact. |
| Trim whitespace off logos, top and footer. Footer: black, logo, big gradient wordmark. | Top logo 170 px (140 px on phones); footer logo 150 px; wordmark `clamp(40px,12vw,148px)` with gradient `#d9d9de` → `#55555f`, text clipped | Logo PNGs were 3600×3600, mostly empty. Footer styled after `website-footer-design.png`. |
| Logo strip: grayscale, muted. | `.logos img{height:44px;max-width:150px;filter:grayscale(1);opacity:.75}` (34 px / 110 px on phones); mini grid in section 3 with 30 px logos | Keeps the brand logos from overpowering the page |
| Pick strong, dark, high-contrast images over mostly-white ones. Show a contact sheet before choosing. | Course card: deck slide 3 (dark "Lesson 1" title) instead of the white cover | "Looks thin" |
| Fonts (client test): Poppins 800 for headings, Lato for body, Caveat for handwritten notes | `brand-kit.md`. Kit scale: h1 `clamp(40px,6.4vw,76px)`, h2 `clamp(30px,4.2vw,50px)`, h3 `clamp(21px,2.3vw,27px)`, `.lede clamp(18px,1.9vw,21px)`, body 18px/1.65, `.hand clamp(24px,2.8vw,32px)` rotated −2°, `.btn` padding 19px 34px at 16px uppercase | #16 |
| Alert bar: dark band, uppercase, brand-color bottom rule | 14 px, 700 weight, `.06em` tracking, padding 11px 16px, `border-bottom:3px solid var(--hi)` | #17. Later made bigger (12.5 px on mobile per later rules) with a gradient after the JJ Smith reference. |
