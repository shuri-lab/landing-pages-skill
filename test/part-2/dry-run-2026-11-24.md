# Blind test, Nov 24 2026

A fresh Claude agent that had never seen this project built the whole Part 2 for the made-up client (a yellow bakery brand, so nothing like Rickey's), using only the playbook.

- **Result:** checkout, bump, upsell, thank-you, three emails and the GHL text sheet. Both tools passed. It chose the right bump and upsell, counted the real number (22, not "30+"), refused "today only", "10x" and the public PDF link, and used the client's own guarantee for the upsell.
- **Its own score:** 79/100, about 10 lower without the CSS fixes it made for the yellow brand. No one else graded it.
- **It found about 40 problems.** Fixed the same day: light brands handled automatically; numbers need a source; 32 bad inputs are now refused (`probes.py`); optional proof, founder note, questions and jump link; contrast, logo and more screen sizes checked; per-client CSS files; a way to accept a settled warning; a full question list for the client; clearer image and logo rules.
- **Second blind test, same day,** another fresh agent with the improved version: 0 to fix on its first build, all pages pass, right choices again, real proof and founder note used. Its own score: 77/100. It attacked the rules and found they covered too few fields, that phone buyers never saw the checkout guarantee, a yes/no bug and a dead email link. All fixed: the rules now read every buyer-facing field and `probes.py` has 52 bad inputs, all refused.
- **Not re-tested:** nobody has run the version after that second round from zero, and no page made with Part 2 for a new client has gone live or had visitors. The phone guarantee under the order button has only been seen in the preview.

Still true: the tools check rules, not whether a claim or a source is true, or whether the copy sells. A person has to read it.
